# ዲሊጀንት ትምህርት ቤት ማኔጅመንት ሲስተም (Dilijent School MIS)

የኢትዮጵያ ስርዓተ-ትምህርት ደረጃዎችን ያሟላ የትምህርት ቤት መረጃ አስተዳደር፣ የተማሪዎች እና የመምህራን መዝገብ፣ ተለዋዋጭ የውጤት ምዘና እና አቴንዳንስ መከታተያ ሲስተም።
Comprehensive Ethiopian School Management System featuring dynamic assessment schemes (Public & Private school models), teacher-student rosters, attendance tracking, and printable report cards.

---

## 🌐 በ GitHub Pages የቀጥታ ዌብሳይት ሊንክ (Live Website Link) ለማግኘት

ይህንን ፕሮጀክት ወደ GitHub ከሰቀሉ በኋላ በ 1 ደቂቃ ውስጥ ነፃ ቋሚ ድረ-ገጽ ለማድረግ የሚከተሉትን ቀላል ደረጃዎች ይከተሉ፦

1. ወደ GitHub ሪፖዚተሪዎ ይሂዱ።
2. የላይኛውን **Settings (⚙️)** ሜኑ ይጫኑ።
3. በግራ በኩል ካሉት አማራጮች **Pages** የሚለውን ይምረጡ።
4. በ **Build and deployment** ስር፦
   * **Source** የሚለውን **GitHub Actions** ያድርጉት (ወይም **Deploy from a branch** መርጠው Branch: `main`፣ Folder: `/docs` ወይም `/(root)` ይምረጡ)።
5. **Save** ይበሉት!

🎉 **በ 30 ሰከንድ ውስጥ የራስዎ ቋሚ የትምህርት ቤት ሊንክ ይሰጥዎታል፦**
```
https://<የእርስዎ-username>.github.io/<የፕሮጀክቱ-ስም>/
```
ይህ ሊንክ በማንኛውም ስልክ፣ ታብሌት እና ኮምፒውተር ላይ ያለ ምንም Google login በቀጥታ ለሁሉም ተማሪዎች፣ ወላጆች እና መምህራን ይከፍታል!

## 🌟 ዋና ዋና አገልግሎቶች (Key Features)
* 🏛️ **ተለዋዋጭ የኢትዮጵያ ስርዓተ-ትምህርት ምዘና (Dynamic Assessment Scheme):** ለመንግስትም ሆነ ለግል ትምህርት ቤቶች በርዕሰ-መምህር ገፅ የሚዋቀር።
* 📝 **የተሟላ የውጤት ማስገቢያ (Add / Edit Grade Modal):** መምህራን ለተለያዩ የትምህርት ዓይነቶች ነጥብ የሚያስገቡበት እና በ `localStorage` የሚቀመጥ።
* 📜 **ኦፊሴላዊ የተማሪ ውጤት ካርድ (Report Card):** በቀጥታ በፕሪንተር (Print) የሚወጣ።
* 📅 **የዕለት አቴንዳንስ (Daily Attendance):** በአንድ ክሊክ የሚቀየር (ተገኝቷል፣ ዘግይቷል፣ ቀሪ)።
